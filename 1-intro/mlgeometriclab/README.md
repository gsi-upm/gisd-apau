# Geometric Models Lab

Laboratorio docente interactivo para explorar la geometría de modelos clásicos de Machine Learning.

## Objetivo

Comparar, sobre los mismos datasets 2D, Linear Regression como baseline de clasificación, Logistic Regression, Perceptron, kNN, SVM y k-Means. El alumnado puede modificar hiperparámetros y observar cómo cambian la frontera de decisión y las métricas.

## Experimentos MVP

1. Linear Regression → Logistic Regression como baseline lineal.
2. Flexibilidad de kNN al cambiar k.
3. Límites de los modelos lineales con Moons/Circles.
4. SVM Linear → RBF; explorar C y gamma.
5. k-Means sin etiquetas y comparación conceptual con las clases.

## Uso

Aplicación estática HTML/CSS/JavaScript compatible con GitHub Pages. No requiere backend.
